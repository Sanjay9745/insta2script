A quick guide to your workspace
  1. Add a video. Upload a saved Reel or load a CORS-enabled direct video URL. Instagram page URLs cannot be resolved by this standalone file. Files are limited to 250 MB and 15 minutes to protect browser memory.
  2. Set the range. Start and end are seconds in the original video. “Frame every” controls the spacing between extracted stills. Local processing needs no key or internet.
  3. Choose an AI path. Video mode sends the original file (up to 12 MB). Extracted-media mode sends frames and audio for the selected range; the JSON request is capped at 18 MB. Extract again after changing the range.
  4. Stay on the free tier. Create a key for an unbilled project in Google AI Studio. Do not enable billing. A quota error stops the request; wait for your quota to reset. The model list checks availability, not pricing or billing.
  5. Take your work with you. Download frames, WAV audio, script, or subtitles. The handoff ZIP contains a prompt and extracted media. Unzip it before attaching supported files to a chat. Share uses your system share sheet, where supported.
  6. Use a modern browser. Open this file in Chrome or Edge. Codec support varies. If a local-file origin blocks the API or clipboard, serve this same file with python -m http.server 8000 and open it at http://localhost:8000. This only serves the HTML; media processing remains in your browser.
